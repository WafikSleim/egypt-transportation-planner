The ops surface leads on purpose. Every fault this project has had produced plausible output — a walk-only itinerary looks like an answer, and an empty graph builds without an error. The walk-only rate is the single number that would have caught it on day one, so it gets the largest tile, a severity stripe, and the runbook command directly underneath.
